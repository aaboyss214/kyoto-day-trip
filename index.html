방문 순서와 예상 시간입니다. 체크박스로 방문 완료를 표시할 수 있고, 기록은 현재 브라우저에 저장됩니다.

이동할 때 꼭 확인하세요
  • 호텔 → 후시미이나리: 미나미모리마치 → 기타하마 → 게이한 후시미이나리 (전철)
  • 후시미이나리 → 기요미즈데라: 후시미이나리 → 기요미즈고조 (게이한 전철) 이후 도보 약 25분. 오르막길입니다.
  • 기요미즈데라 → 폰토초: 산넨자카·니넨자카·야사카 신사·기온·니시키시장을 거쳐 도보 관광
  • 폰토초 → 호텔: 기온시조 → 기타하마 → 미나미모리마치 (전철)
  • 지도 위의 선은 방문 순서 참고용 직선이며, 실제 길이나 철도 노선을 나타내지 않습니다. 실제 이동은 '구글 지도 길찾기'를 누르세요.
  • 기요미즈데라의 실제 입구는 니오몬(仁王門) 방향입니다. 일부 지도 앱이 통행할 수 없는 경로를 제안할 수 있습니다.
